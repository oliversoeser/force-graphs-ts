# force-graphs-ts

Demo: https://www.oliversoeser.com/force-graphs-ts/web/

This demo shows how different University of Edinburgh courses relate to each other. The data is sourced from the University of Edinburgh's Degree Regulations and Programmes of Study ([DRPS](http://www.drps.ed.ac.uk/)) website. All DRPS data is © Copyright 2024 The University of Edinburgh.
